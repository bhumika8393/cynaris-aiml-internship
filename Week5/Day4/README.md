# W5D4 – Semantic Search with ChromaDB

## Objective

Build a semantic search system using ChromaDB and integrate it with Ollama for Retrieval-Augmented Generation (RAG).

## Features

- Installed ChromaDB
- Created vector collections
- Added 20 embedded documents
- Performed cosine similarity search
- Applied metadata filtering
- Embedded a PDF
- Retrieved top-3 relevant chunks
- Generated answers using Ollama (llama3.2:3b)

## Technologies

- Python
- ChromaDB
- Sentence Transformers
- Ollama
- Llama3.2:3b
- PyPDF
- Requests

## Learning Outcomes

- Understood semantic search
- Learned vector embeddings
- Built a basic RAG pipeline
- Integrated ChromaDB with Ollama
