# W5D3 - ChromaDB Vector Store & PDF Retrieval

## Objective

This project demonstrates how to build a simple Retrieval-Augmented Generation (RAG) pipeline using ChromaDB and Ollama.

## Features

- Install and configure ChromaDB
- Create a persistent vector database
- Add 20 embedded documents
- Perform semantic similarity search
- Apply metadata filtering
- Read a PDF using PyPDF
- Split PDF into chunks
- Store PDF embeddings in ChromaDB
- Retrieve top-3 relevant chunks
- Generate answers using Ollama (llama3.2:3b)

## Technologies Used

- Python
- ChromaDB
- Sentence Transformers
- Ollama
- Llama3.2:3b
- PyPDF
- Requests

## Output

- Successfully stored document embeddings
- Performed semantic search
- Retrieved relevant PDF chunks
- Generated answers using a local LLM

## Learning Outcomes

- Understood vector databases
- Learned embeddings and semantic search
- Built a basic RAG application
- Integrated ChromaDB with Ollama
