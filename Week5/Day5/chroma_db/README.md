# Week 5 Project - Local Q&A Bot

## Objective

Build a local question-answering bot using Ollama and ChromaDB.

## Features

- Local LLM using Ollama
- ChromaDB vector database
- PDF embedding
- Semantic search
- Top-3 chunk retrieval
- Retrieval-Augmented Generation (RAG)
- Interactive Q&A
- Model comparison

## Models

- llama3.2:3b
- qwen2.5:3b

## Technologies

- Python
- Ollama
- ChromaDB
- Sentence Transformers
- PyPDF
- Requests

## Results

- Successfully answered questions using PDF context.
- Compared two local LLMs.
- Built a fully local RAG application.
